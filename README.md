# Debasish Nandy - Production AI Engineering Dynamic Portfolio

Modern, dynamic responsive portfolio website for **Debasish Nandy (Lead AI Engineer & Systems Architect)**, deployed via GitHub Pages through GitHub Actions.

## Target Audience
- Senior & Lead AI Engineering Recruiters
- VP / Head of AI Hiring Managers
- Global Remote AI Engineering & Research Teams

## Core Highlights & Features
- **Exhaustive Resume Alignment**: Features 100% of the candidate's verified career history, all 9 enterprise production projects (BFSI, Supply Chain, Telecom, Multimodal CFA), education (KIIT B.Tech Honors 8.8 CGPA, AHSEC, SEBA), certifications, mentorship achievements, and technical skills.
- **Dynamic `config.json` Configuration**: All numbers, metrics, and quantifiables (years of experience, concurrent users, POCs, accuracy percentages, latencies, notice period) are driven by a centralized `config.json` that hydrates the DOM asynchronously with offline fallback.
- **Modern AI & Agentic Stack**: Showcases hands-on production engineering with **AutoGen**, **CrewAI**, **Crawl4AI**, **DSPy**, **AWS Bedrock Runtime**, **Boto3**, **LangChain**, **LangSmith**, **MLflow**, and **uv**.
- **Privacy First**: Phone number omitted across the public website; contact flows directly through verified email, LinkedIn, and GitHub.
- **Dynamic Project Explorer & Architecture Modal**: Interactive domain filter tabs, live keyword search, dynamic rendering, and deep-dive technical modals with quantified metrics, challenges, and architecture blueprints.
- **Live Skills Search & Category Filtering**: Interactive search across Libraries, Cloud (Azure & AWS), Developer Tools, and Soft Skills.
- **Interactive ATS Resume Viewer**: Built-in modal rendering single-column Harvard ATS text format with 1-click clipboard copy and print/PDF generation.
- **Theme Switcher**: Dark Mode (Default), Cyber AI Glow, and High-Contrast modes saved via `localStorage`.
- **Dynamic KPI Stat Counters**: Smooth counter animations on scroll for 1,000+ Concurrent Users, 5+ YOE, 10+ Enterprise POCs, and 150+ Mentees.

## Tech Stack
- **Languages**: TypeScript, Modern Semantic HTML5, CSS3 Custom Properties (Variables, Grid, Flexbox)
- **Architecture**: Modular ES6+ Modules (`assets/js/`) backed by strict TypeScript source models (`assets/ts/`)
- **Tooling**: `tsconfig.json`, `package.json` with strict type checking
- **CI/CD**: GitHub Actions (`.github/workflows/pages.yml`) deploying directly to GitHub Pages
